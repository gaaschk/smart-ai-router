HOW TO GET STARTED
─────────────────────────────────────────────────────────────────────────

1. Backend Setup:
   $ cd dashboard/backend
   $ npm install
   $ cp .env.example .env
   $ npm run dev

2. Frontend Setup:
   $ cd dashboard/frontend
   $ npm install
   $ npm run dev

3. Ensure running:
   $ smart-ai-router         (Terminal 3)
   $ gbrain serve            (Terminal 4)

4. Visit dashboard:
   http://localhost:5173
