HOW IT WORKS
─────────────────────────────────────────────────────────────────────────────

Step 1: User installs smart-ai-router (runs on localhost:8001)
Step 2: User configures gbrain to point to it
Step 3: GBrain works normally, all requests route through smart-ai-router
Step 4: Smart-ai-router optimizes each request (60%+ cost savings)
Step 5: GBrain gets response back (thinks it came from OpenAI)

Completely transparent. No gbrain changes needed.

USER EXPERIENCE

$ pip install -e .
$ smart-ai-router setup
# Now listening on http://localhost:8001

# Step 2: Configure GBrain (edit ~/.gbrainrc.json)
{
  "provider_base_urls": {
    "openai": "http://localhost:8001/v1"
  }

# Step 3: Use GBrain normally

# Cost optimization happens transparently
